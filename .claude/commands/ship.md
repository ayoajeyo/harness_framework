---
description: 배포 전 최종 점검 후 GitHub에 올리기
---

배포(GitHub에 올려 실제 사용자에게 반영) 전에 아래를 순서대로 확인하라. 하나라도 실패하면 멈추고 이유와 해결책을 알려라.

1. `git status` — 저장 안 된 변경이 있으면 무엇인지 보여주고 커밋할지 묻는다.
2. `git fetch` 후 뒤처져 있으면 `git pull`을 먼저 한다.
3. `package.json`이 있으면 `npm run lint`, `npm run build`, `npm run test`를 실행한다.
4. `privacy-guard` 에이전트로 개인정보·비밀키 점검. 🔴가 있으면 배포 중단.
5. `ui-checker` 에이전트로 디자인 규칙 점검. 문제는 보고만 하고 배포를 막지는 않는다.
6. 버전 표기가 있는 앱이면(예: `APP_VERSION`, `manifest.json`, 서비스워커 캐시 이름) 버전을 올렸는지 확인한다. 안 올렸으면 올리자고 제안한다. 이유: 올리지 않으면 사용자 폰에 이전 화면이 남는다.
7. 모두 통과하면 무엇이 배포되는지 3줄로 요약하고, 사용자 확인을 받은 뒤 `git push` 한다.

결과는 체크리스트 표(항목 | ✅/❌ | 비고)로 보여준다.

# UI 디자인 가이드

> 기본값은 **심플·깔끔**이다. 프로젝트마다 바꿀 필요가 없으면 그대로 쓴다. 바꾸고 싶은 값만 고친다.
> 코드에 옮기는 방법(CSS 변수)은 `.claude/skills/clean-ui/SKILL.md`에 있다.

## 디자인 원칙
1. **덜어낸다** — 장식보다 여백. 한 화면에 강조는 하나.
2. **도구처럼 보인다** — 매일 쓰는 업무 도구. 광고 페이지처럼 꾸미지 않는다.
3. **같은 것은 같게** — 같은 뜻의 버튼은 모든 화면에서 같은 이름·모양·위치.

## 색상
| 용도 | 값 | 쓰는 곳 |
|------|------|------|
| 포인트 (네이비) | `#1E2A4A` | 주 버튼, 선택된 탭, 제목 |
| 본문 글자 | `#1F2328` | 일반 텍스트 |
| 보조 글자 | `#6B7280` | 날짜, 설명 |
| 구분선 | `#E5E7EB` | 테두리, 줄 |
| 카드·입력칸 | `#FFFFFF` | |
| 페이지 배경 | `#F7F7F5` | |
| 정상 / 주의 / 위험 | `#15803D` / `#B45309` / `#B91C1C` | 상태 표시에만 |

## 글자
| 용도 | 크기 | 굵기 |
|------|------|------|
| 화면 제목 | 20px | 700 |
| 소제목 | 16px | 600 |
| 본문 | 15px | 400 |
| 보조 | 13px | 400 |

글꼴: Pretendard → Noto Sans KR → 시스템 기본 순서.

## 컴포넌트
| 요소 | 모양 |
|------|------|
| 카드 | 흰 배경, 1px 회색 테두리, 모서리 10px, 안쪽 여백 16px, 그림자 없음 |
| 주 버튼 | 네이비 채움 + 흰 글자, 높이 44px 이상. **화면당 1개** |
| 보조 버튼 | 흰 배경 + 회색 테두리 |
| 입력칸 | 높이 44px, 회색 테두리, 선택 시 네이비 테두리 |
| 팝업 | 흰 카드 + 반투명 검정 배경, 블러 없음 |

## 레이아웃
- 모바일 390px 기준으로 먼저 만든다. 넓은 화면에서는 최대 폭 480px(앱) / 960px(관리 화면)로 가운데 배치.
- 여백은 8의 배수만: 8 · 16 · 24 · 32px.
- 글은 왼쪽 정렬. 가운데 정렬은 빈 화면 안내 같은 짧은 문구에만.

## 하지 마라 (AI 티 나는 디자인)
| 금지 | 이유 |
|------|------|
| 그라데이션 글씨, 배경 그라데이션 | 템플릿 느낌 |
| 글래스 블러(backdrop-filter) | 가독성 저하, AI 템플릿 징후 |
| 네온·글로우 그림자 | 산만함 |
| 보라·인디고 색 | "AI = 보라" 클리셰 |
| 배경 원형 블러 장식 | 의미 없는 장식 |
| 이모지를 아이콘 대신 사용 | 기기마다 모양이 달라 일관성이 깨짐 |
| 버튼마다 다른 색 | 무엇이 중요한지 흐려짐 |
